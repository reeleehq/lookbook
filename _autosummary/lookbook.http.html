lookbook.http¶

HTTP surface for lookbook, built with qh over FastAPI.

Each HTTP route is a thin function that takes JSON-able args and returns a JSON-able dict. The route functions are the only thing this module adds — all real work is delegated to the existing facade.

Build the app with mk_lookbook_app() and run it with serve() (or use the lookbook serve CLI command).

lookbook.http.compare_to_reference(*, reference_paths, candidate_path, embedder='arcface', threshold=0.85, aggregation='max', normalization='rescale')[source]¶

Identity/likeness of a candidate vs a locked reference (or pool).

The reference-supervisor verb: returns a normalized similarity in [0, 1] (1 = same identity) plus an advisory passed flag. Pass one or more reference_paths (server-local image paths) and a single candidate_path. embedder selects the space — "arcface" for faces (default), "clip" / "dinov2" for scenes/architecture.

The pass/fail is advisory — the caller decides whether to act on it.

dict

lookbook.http.get_image(image_id)[source]¶

Return the raw bytes of an image by id.

The server reads from stores.images[image_id]["path"]. If the entry is missing, returns a 404-style error dict (FastAPI surfaces this as a JSON response; a future iteration may switch to a streaming binary response via FastAPI’s Response).

lookbook.http.mk_lookbook_app(*, app=None, **kwargs)[source]¶

Build a FastAPI app exposing the lookbook HTTP surface.

Each function becomes a POST endpoint with a JSON body matching its keyword arguments. Use the auto-generated /docs (Swagger) or /redoc for interactive exploration. Disabling qh’s convention-based routing keeps the path scheme uniform — every route is POST /<verb> and takes a JSON body — which is the pattern most agent clients (and our future MCP layer) expect.
